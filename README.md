# Perfume Store - Simple Frontend Project 🌸🛍️

This is a basic **Frontend web project** for a simple **perfume store**. The project was created as part of my early practice with web development, focusing on building UI layouts using **HTML**, **CSS**, and a little **JavaScript**.

---

### ✨ **Features**:
- 🧴 Display a list of perfumes with names, prices, and images
- 🛒 Simple "Add to Cart" button (non-functional/demo only)
- 🎨 Responsive layout with elegant design
- 💡 Focused on improving HTML structure and CSS styling

---

### 🛠️ **Technologies Used**:
- **HTML5**
- **CSS3**
- **JavaScript (basic)**

---
**Notes**:

This is a static frontend project with no backend functionality.

It was created to practice layout design, component styling, and UI structurin
